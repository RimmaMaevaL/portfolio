# AI Self-Care Bot

A personal Telegram MVP that checks mood and energy, selects suitable self-care tasks, generates contextual AI suggestions, logs daily state, accepts notes, and provides weekly statistics.

## Stack

`n8n` · `Groq / LLM API` · `Telegram` · `Google Sheets`

## Honest technical reflection

The workflow demonstrates context-aware suggestions rather than generic advice. The next improvement is replacing the demo weekly dataset with a real historical query and adding persistent memory so the bot can reason about trends.
